# Project Overview

## Summary

This project is a Unity PC multiplayer tower defense game with FPS elements.

Core concept:

- The player controls a character on top of a tower.
- The player shoots enemies from an elevated position.
- The project combines direct player action with defensive or offensive wave management.

## Planned Modes

### PvE Survival Competition

Players survive against enemy waves and compare results such as survival time or score.

### PvP Attack and Defend

Players defend their own side while sending units toward the opponent.

### Co-op Defense

Players work together against shared enemy pressure.

## Current Repository State

- Unity project scaffold exists.
- `Assets/Scenes/SampleScene.unity` is currently available.
- The repository is still early-stage and does not yet represent the final gameplay structure.

## Constraints

- Target platform: PC.
- Primary language: C#.
- Multiplayer is a core project requirement, not an optional extension.
