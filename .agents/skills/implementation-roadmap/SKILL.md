# Implementation Roadmap

## Phase 1

- Keep the Unity project healthy and runnable.
- Lock the working Unity version.
- Add the first multiplayer packages and baseline configuration.
- Build the main menu and placeholder host or join UI.

## Phase 2

- Implement the lobby scene.
- Add ready-state synchronization.
- Add host-controlled match start.
- Add gameplay scene loading.

## Phase 3

- Implement player spawning.
- Implement enemy wave spawning.
- Implement tower placement validation.
- Synchronize health, score, and round state.

## Phase 4

- Implement result summary.
- Implement restart, next level, and return-to-lobby flow.
- Test latency, disconnect, and gameplay-state consistency.

## Notes

This roadmap is directional and should be revised once actual gameplay systems and folder structure
stabilize.
